REVIVE
---------
revivablecorpse
	Variables:
		revive_health_percent
			default: 0.5
        revivespeedmult
			default: 1

	Methods:
		SetCanBeRevivedByFn(fn)
			sets canberevivedbyfn to fn
		CanBeRevivedBy(reviver)
			returns result of canberevivedbyfn, if nil returns true
		GetReviveHealthPercent()
			returns revive_health_percent
		GetReviveSpeedMult()
			returns revivespeedmult
		SetReviveHealthPercent(percent)
			sets revive_health_percent to percent
		SetReviveSpeedMult(mult)
			set revivespeedmult to mult

corpsereviver
	Variables:
		additional_revive_health_percent
			default: 0
		reviver_speed_mult
			default: 1	
	
	Methods:
		GetAdditionalReviveHealthPercent(percent)
			returns additional_revive_health_percent
		GetReviverSpeedMult()
			returns reviver_speed_mult
		SetAdditionalReviveHealthPercent(percent)
			sets additional_revive_health_percent to percent
		SetReviverSpeedMult(mult)
			sets reviver_speed_mult to mult

ADMIN/DEBUG MENU
-----------------
Any items you create that you want in the admin/debug menu needs to be created with ForgePrefab() and NOT Prefab().
ForgePrefab(name, fn, assets, deps, force_path_search, category, is_mod, atlas, image, mod_icon, stats, abilities, swap_build, swap_data)
	Description:
		Creates a Prefab for the given entity and adds it to the forge item list to be displayed in the admin/debug menu.
	Parameters:
		name, fn, assets, deps, force_path_search: these are the same parameters from the regular Prefab()
		category: this is the type of entity, currently supports these types:
			"ENEMIES", "WEAPONS", "ARMOR", "BUFFS"
		is_mod: set the is to true if this is a separate mod from Forged Forge
		atlas, image: this is the icon for the entity
		mod_icon: This is a custom icon that will appear in the top right hand corner of this entitys icon. Uses the same atlas as above.
		stats: Give the stats of the entity like this: {stat1 = x, stat2 = y ...}. Currently supported stats:
			dfasdgagasdga
		abilities: If the entity is a mob then place abilities here like this: {ab1, ab2} etc
